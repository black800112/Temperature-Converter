# 交接

目的:把目前的工作進度存成檔案,讓下一個對話視窗不用重新說明,節省 token。

## 步驟

1. 回顧這次對話做了什麼,必要時用 `git status` 和 `git diff --stat` 確認改了哪些檔案。
2. 在專案根目錄寫入(覆蓋)`HANDOFF.md`,內容保持簡短,用簡單的中文,格式如下:

```markdown
# 交接紀錄

更新時間:<日期>

## 目標
我們正在做什麼(一兩句話)

## 已完成
- ...

## 進行中 / 卡住的地方
- ...

## 下一步
1. ...
2. ...

## 重要檔案
- 路徑:用途

## 備註
使用者目前學到哪裡、需要特別注意的事
```

3. 只寫接手時真的需要的資訊,不要貼大段程式碼,不要重複 CLAUDE.md 已有的內容。
4. 寫完後用簡單的話告訴使用者:交接檔已存好,下一個視窗輸入 `/takeover` 就能接手。
