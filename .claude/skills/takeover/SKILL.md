# 接手

目的:讀取上一個對話留下的交接檔,不用使用者重新說明,直接繼續工作。

## 步驟

1. 讀取專案根目錄的 `HANDOFF.md`。如果檔案不存在,告訴使用者「找不到交接檔」,並詢問要從哪裡開始。
2. 只讀交接檔提到的重要檔案,不要一次讀整個專案,以節省 token。
3. 用簡單的中文向使用者簡短回報:
   - 上次做到哪裡
   - 現在的下一步是什麼
4. 問使用者是否要從「下一步」開始,得到同意後再繼續。
5. 繼續工作時,遵守 CLAUDE.md 的規則(簡單對話、一步一步帶著做、不要直接寫完 code)。
